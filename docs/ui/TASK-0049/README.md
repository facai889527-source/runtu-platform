# TASK-0049 账户与注册审核中心

用户账户与注册审核统一放在 `/users`，分开列表、游标、当前页筛选和数量。设置页仅保留注册策略与审核入口，不再加载申请列表。未批准及已拒绝申请不属于用户账户，不计入启用账户数量。

沿用 Segoe UI / Microsoft YaHei UI、浅灰画布、墨色文字与青绿色操作。目录移除整块白底边框，以细分隔、对齐和轻量悬浮态建立层级；手机工具栏保持紧凑。角色显示为所有者、管理员、普通用户，权限语义不变。

共享自定义 combobox/listbox 支持方向键、Home/End、Enter/Space、Escape、输入定位、Tab、外部点击、选中标记和视口约束。弹窗内菜单挂载在原生 dialog 内，保持焦点隔离；关闭审核弹窗后，原列表项已消失时将焦点归还当前页签。

审核详情读取最新状态；批准/拒绝均在弹窗内确认，处理期间防止重复提交。冲突、撤权、404、503 与空态明确反馈；已拒绝详情只读。后端沿用所有者权限、会话复核、Origin/CSRF 和同一事务锁，保证相反决定只能成功一个；审计失败回滚。

拒绝复用现有 `registration_rejected` 审计事件作为持久决定，未批准标记继续为真，保留登录、编辑、授权及降级的关闭保护。该事件是业务决定记录，不能按普通日志清理；未来保留策略变更必须迁移这一决定语义。没有新迁移或表结构变更。
