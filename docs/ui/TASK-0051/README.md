# TASK-0051 个人 Telegram 消息

TASK-0051 取代共享设置语义：所有已登录账户拥有自己的“消息设置”。页面以“我的消息”开头，连接证明和个人偏好分开呈现。设计沿用浅灰 #f5f7f9、白色 #ffffff、墨色 #223641、辅助文字 #60717c、青绿 #087363 与分隔 #e3e9ed，Segoe UI / Microsoft YaHei UI，22px 标题、15px 状态、12–14px 正文。左对齐、860px 内容上限，手机按钮纵向排列，保留 44px 触控与键盘焦点。

先规划再复查：移除不适用于个人绑定的 Token 掩码与任意 Chat ID 输入；让连接状态、一条明确 CTA 和验证步骤承担层级，不增加装饰卡片。配对区仅用一条青绿侧线表达当前操作，字段与事件沿用原有平面分隔。路由页面负责构成，NotificationSettings 负责个人草稿与配对/保存生命周期，复用 PolicySwitch；无新增依赖或复杂动画。

用户需要在本人 Telegram 私聊点击一次性 Start 链接，再回网页确认；候选状态不算已验证，已验证也不自动启用。普通用户拥有相同连接能力，注册提醒按服务端角色禁用。没有真实任务来源的工具结果等类别保持不可用。断开、重连、失败暂停均有明确反馈；所有 API 只操作会话本人。
