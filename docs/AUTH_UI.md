# 认证页面视觉更新（TASK-0038 / TASK-0039）

沿用Vue3 JavaScript、共享认证布局、现有路由/API与系统字体，无外部图片、字体或依赖。桌面以深青/海军灰品牌区与浅色表单区构成一张双栏面板，工具平台文案搭配克制的抽象弧线装饰，移除模块/账户/权限示意；手机收起品牌说明与装饰，保留紧凑品牌头、表单及页脚。基本色为#103F46、#172E3B、#F3F7F7、#526873和#087F75，按钮及背景使用轻量CSS渐变。

登录表单合并为一句“没有账户？ 申请注册账号”，仅后半句是链接。点击链接先查询公开策略：enabled=true才导航/register；false留在/login显示“暂未开放注册”；404/503/网络失败留在/login显示“注册服务暂不可用，请稍后再试”。同一查询进行中忽略快速重复操作，成功查询结果在当前登录组件内复用10秒；失败不缓存，离页取消请求并忽略晚到响应。直接/register仍独立查询策略，关闭时只显示“暂未开放注册”和返回登录；失败显示简洁服务不可用，两者没有刷新按钮，也不显示表单。公共404/503仍显示服务不可用，不能误报为关闭或管理员审核错误。注册启用时保留原有表单、提交后提示与密码清空。后端开关继续在写入事务中权威校验，没有自动开启策略。

共享布局管理登录/注册页标题与统一输入、按钮、错误样式；移除旧页面重复CSS。字段有明确label，autocomplete与键盘顺序保留，操作目标至少44px，密码不持久化；提交中禁用与错误状态保留。文字/主要按钮对比度至少4.5:1，输入边界至少3:1；焦点清晰，prefers-reduced-motion下关闭过渡，无自动播放动画。

会话确认、同源Cookie、CSRF、登录错误401/403、returnTo深链、匿名注册和owner审核权限均沿用现有实现；未新增身份或注册API。未修改后端/迁移、真实数据库或凭据，未重启已有服务或部署。

验证：Node28项和生产构建通过；Python144 passed、11项在线PG本地跳过。Chrome全API夹具1440/390/360覆盖新链接预检、快速点击去重、关闭留页、404/503/网络失败、启用跳转、离页取消、键盘Tab、登录提交中禁用/密码清空、登录401/403/503、注册关闭/开启/404/503、认证跳转及原模块/owner审核流程；屏宽溢出与减少动态效果检查。截图仅为全API夹具，密码为空，不是真实账户。CI实际结果见PR和协调状态。
