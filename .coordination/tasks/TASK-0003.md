## 开发目标
初始化可运行、可测试的通用模块化平台最小骨架，不开发具体服务器安全业务功能。

建议结构（可做合理调整并在 PR 解释）：
- backend/：Python FastAPI 应用工厂、/api/health、模块清单/注册协议（最小可运行、内存示例即可）、配置加载、依赖声明
- frontend/：Vue 3 + Vite 最小页面，显示平台名称、后端健康状态、模块列表；避免复杂 UI 框架
- tests/：后端 health 和模块注册基本测试
- docs/DEVELOPMENT.md：Windows + PyCharm 打开项目、Python 虚拟环境、安装依赖、运行后端、运行前端、运行测试的准确命令
- .env.example：仅虚拟示例值，不放真实密钥
- .gitignore：保持 .idea/、*.iml、*.ipr、*.iws、.venv/、node_modules/、dist/、.env 等不进入版本控制

## 技术原则
FastAPI / Python，Vue 3，前后端独立；PostgreSQL 作为未来中心数据库，但本次不要求启动数据库。模块注册接口应允许未来不同业务模块扩展，避免过度工程化。避免新增 Redis、Docker、复杂登录系统等非本次范围。保持公共仓库无秘密。
