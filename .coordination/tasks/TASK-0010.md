## 功能要求
1. 使用现有依赖优先实现浏览器 URL 导航，至少支持 `/` 仪表盘、`/modules` 模块管理、`/modules/:moduleId` 模块详情、`/settings` 设置占位；可根据项目现有构成选择轻量路由实现或 Vue Router，但若新增依赖须说明权衡并维护锁文件，不引入不必要的大依赖。
2. 直接访问、刷新、浏览器后退/前进、复制 URL、未知路径的友好 404 页面都应正确；保留模块详情的 404/503 网络错误与路由不存在的区分。对模块 ID 做安全 URL 编码/解码，不能把用户输入拼接成外站请求。
3. 与已有搜索、筛选、侧栏、移动抽屉交互保持一致；导航后标题、激活菜单、焦点和抽屉状态正确，避免键盘焦点丢失或旧请求覆盖新路由。
4. 验证 Vite 本地 dev server 的 history fallback 与现有 API proxy 不冲突；若静态生产部署需要 fallback，提供清晰的 Nginx `try_files` 示例（只在文档，不修改服务器）。若静态环境无法支持 history fallback，明确权衡并选择稳定方案。
5. 不新增登录假功能、未经认证的写接口、统计/营收虚假数据或外部遥测。继续 Vue 3 + JavaScript；参考已安装的 `frontend-design` 与 `vue-best-practices`，但不执行 Skill 安装或外部 CLI。视觉风格与 TASK-0009 保持一致，修复明显的交互或无障碍问题，避免无关大重构。
6. 为导航、URL 解析、未知路由、模块详情、浏览器前进后退添加可重复测试；更新 `frontend/tests/browser-smoke.mjs` 覆盖桌面与 390px 移动端直接访问、刷新、后退、手机抽屉、无水平滚动及 JS 异常。真实环境无法执行时如实说明。
