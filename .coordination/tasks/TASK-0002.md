# TASK-0002 — 无人工干预的自动领取验证

## 目标
验证 Codex Windows 桌面应用已经配置的一分钟 heartbeat 是否会在用户**不向 Codex 发送新消息**的情况下，自动读取 GitHub main 上的新信号、领取任务、执行并提交 PR。

## 执行要求
1. 只有由现有原生定时任务自动唤醒时才执行本任务；若是用户手动启动，请明确记录触发方式，不能把它算作无人值守成功。
2. 从远程 main 获取 .coordination/signal.json，核对 task_id=TASK-0002、version=2、status=ready；读取本任务文件，检查本地持久化状态与 GitHub 现有 PR，防止重复。
3. 在 codex/TASK-0002-auto-poll 分支新增 docs/AUTO_POLL_VERIFICATION.md，记录真实触发时间（带时区）、触发方式（自动/手动）、远程读取成功与否、沙箱/网络授权情况、任务执行时间、是否发现重复执行。不要编造观察记录。
4. 如果自动任务没有获得网络权限或无法提交 PR，尽可能在允许范围内记录阻塞，并通过已支持的渠道反馈。不要通过禁用沙箱或扩大权限绕过。
5. 仅修改上述验证文档；运行 git diff --check，确认 .idea/ 等 IDE 文件没有被提交。推送分支并创建指向 main 的 PR，标题包含 TASK-0002，说明 commit SHA 和检查结果。
6. 不自动合并 PR，不修改 main，不开发业务功能，不安装外部调度程序，不部署服务器。

## 验收
- 用户没有向 Codex 手动发送新消息，Codex 自动产生 TASK-0002 PR，且有可核对的时间与触发方式记录，才能认定自动闭环成功。
- 若没有 PR，不可推断定时任务一定失败；需进一步排查唤醒、网络和授权。
- 同一 task_id/version 不得重复创建 PR。
